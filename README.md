# Huffman Coding in C

Утилита для сжатия и распаковки файлов алгоритмом Хаффмана на чистом C. Строит дерево по частотам символов, генерирует префиксные коды и записывает данные побитово.

## Возможности
- Подсчёт частот байтов входного файла.
- Построение дерева Хаффмана с детерминированным порядком слияния (при равных частотах сортировка по символу), поэтому дерево однозначно восстанавливается при распаковке.
- Побитовое кодирование: длина данных в битах (8 байт) и упакованные биты.
- Декодирование обходом дерева, восстановленного из таблицы частот.
- Вывод статистики: размеры файлов и процент сжатия.

## Сборка и запуск
```bash
make
./huffman -e examples/input.txt output.bin codes.txt     # сжатие
./huffman -d output.bin restored.txt codes.txt           # распаковка
```

`codes.txt` содержит таблицу частот: она нужна для распаковки.

## Пример
Вход: `BBBDDDDDDAAAAIIIIMM` (19 байт)
```
Unique symbols: 5
Encoded. Total bits: 43
Input size:  19 bytes
Output size: 14 bytes
Compression: 26.3%
```
Размер таблицы частот в процент сжатия не входит.

## Структура
- `main.c` — разбор аргументов, режимы `-e` / `-d`
- `node.c` — создание листьев и внутренних узлов
- `min_heap.c` — массив узлов и выбор минимумов
- `freq.c` — подсчёт частот
- `codes.c` — генерация кодов, освобождение дерева, сравнение файлов
- `bit_io.c` — побитовая запись и чтение
- `rebuild_tree.c` — восстановление дерева из частот

## Стек
C (C99) · указатели и динамическая память · бинарное дерево · битовые операции · файловый ввод-вывод

## Ограничения
- Таблица частот хранится в отдельном текстовом файле, а не внутри сжатого файла.
